# Android 2.11.1 · build 75

修复 `v2.11.0` 更新后双生日合并展示与农历生日切换显示问题。

## 修复内容

- **双生日合并行完整展示公历与农历**：首页「即将到来」清单中的双生日合并条目改为双行清晰排布，标题下方完整展示 `公历 X月X日 · 农历 X月X日`，不再受横向挤压省略，同时补齐快捷完成与多语言支持。
- **日期类型平铺直选**：新建/编辑页的 `新历生日 / 农历生日 / 节假日` 改为直接平铺切换，无需再点开折叠菜单寻找农历生日。

## 安装与覆盖升级

[Release 与 APK 下载](https://github.com/tsumon/reminder-app-android/releases/tag/v2.11.1)。包名（`com.reminderapp`）、最低系统版本（`minSdk 26`）及正式签名证书 SHA-256（`0ea509a1dc9461c291a2db47caf5f055d83e4108fb28c3e87ed4fa62bead7038`）完全不变，可直接覆盖已安装的 `v2.11.0` 或更早正式版本。
