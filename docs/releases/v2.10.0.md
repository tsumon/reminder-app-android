# Android 2.10.0 · build 73

**Warm-Paper & Deep-Teal** 界面与交互升级，以及核心排期、统计、AI 提示词、小组件与 WebDAV 同步一致性修复。

## 界面与体验优化

- **全新设计系统与实时换肤**：采用 Warm-Paper（`#F6F4EF` / `#FFFFFF` / `#E7E2D8`）与深色画布（`#111315` / `#1A1D20` / `#2A2F35`），默认 Deep-Teal 主色（`#0F766E` / `#2DD4BF`）；切换主题色或深浅模式通过 Compose 状态即时生效，不再整页重建闪烁。
- **首页更克制、操作更直接**：顶栏聚合搜索与快捷 `+` 新建入口；折叠式一句话快速创建栏；用一致的 Material 矢量图标容器替代零散 emoji；逾期/提醒中卡片行内提供 **确认 / 稍后 / 跳过**，确认附带触觉反馈；列表底部留白扩大至 `148.dp`，避免与悬浮按钮/底栏重叠。
- **表单与策略打磨**：新建/编辑区分页标题；自定义天数、公历/农历月日使用缓冲输入，支持清空后重输；支持汉字农历（如 `农历正月初一`、`农历腊月廿八`）并可自动拆分创建（公历/农历）双生日；优先级改为清晰色点；勿扰时段支持原生 Material 3 `TimePicker` 选择器。
- **统计洞察**：漏掉/完成/跳过汇总整合进顶部 Hero 卡片；连续打卡天数与 16 周热力图始终基于全量记录计算，不受本周/本月筛选截断；最常忘记时段改用数字序号徽章。
- **本地备份与冲突快照恢复**：设置页新增「恢复本地备份」（读取下载目录中的 `reminder_backup_*.json`），同步设置页新增「同步前本地快照」恢复列表；自动/手动同步冲突统一跳转与清除状态。
- **桌面小组件**：新增 `values-night` 深色适配与多语言字符串，重构为矢量铃铛图标与 `30 分钟` 刷新节奏；仅当提醒已到点/通知中/逾期时显示「稍后」按钮，点击卡片空白处也可直达应用。

## 核心逻辑修复

- **节假日与调休补班顺延**：`ReminderEngine.deferToWorkdayWithStatus` 接入法定调休补班状态，调休上班日不再误判为周末顺延。
- **跨年与农历闰月/29日回退**：`calculateDateNextTrigger` 与 `occursOnDate` 扩展至 `(year - 1)..(year + 8)` 并补全农历大月 30→29 日回退；规则提醒 `occursOnRule` 严格校验 `rulePeriod`（月/季/年）。
- **统计漏掉与 AI 提示词**：区分首次通知与重响（`note = "primary"` vs `"retry:..."`），修正“漏掉”按重试日期去重口径与 AI 一周漏掉汇总；修复 `AITools.todayContext()` 格式化占位符及动态 `systemPrompt`。
- **WebDAV 同步去重**：引入规范化 SHA-256 内容指纹与 `pendingUpload` 持久化，远端内容一致时零冲突跳过；首 sync 增加墓碑冲突检查；诊断页改用含停用条目的全量统计；更新检测优先匹配对应版本 Tag 资产。
